# Python Network Scanner

## About
A beginner-friendly Python TCP port scanner
developed for authorized security testing.

## Objective
Identify open TCP ports on a local target.

## Technologies
- Python
- Socket Library
- TCP/IP Networking

## Features
- Scans selected TCP ports
- Detects open ports
- Uses connection timeouts
- Displays scan results

## Legal Disclaimer
This tool is intended for authorized testing
and educational purposes only.

## How to Use

1. Install Python 3.
2. Clone this repository.
3. Run the scanner:

   python scanner.py

4. Enter an authorized target IP address.

## Learning Outcomes
- Python socket programming
- TCP port scanning
- IP validation
- Service-name lookup
- Network reconnaissance
